## Observations

- Non-ready rows carry an `expiresAt` in the cache file, but the
  coordinator never serves them as fresh (`src/status/coordinator.rs`,
  `cache_document_non_ready_row_is_never_fresh`); the file value is not
  the freshness authority.
- After the cache was cleared, the first rewrite contained only the
  Claude row; other enabled providers were appended by later collections.
  Not part of this amendment; noted for follow-up if it affects the
  first-poll bar state.
